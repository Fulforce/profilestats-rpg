# Example Theme Licensing and Provenance

Replace this file before submitting a theme.

## Theme Text and Data

Describe who wrote the route names, titles, achievements, descriptions, coordinates, thresholds, and palette values. State the license terms for that text and data.

## Visual Assets

`assets/character.svg` is placeholder artwork from the contributor theme template. Replace it with original or properly licensed artwork before submitting a production theme.

For every visual asset, document:

- who created it;
- whether it is original work or adapted from another source;
- the license or permission that allows inclusion;
- any required attribution.

## Fan Theme Notice

If this theme references an existing fictional world, game, book, film, brand, person, place, or trademark, state clearly that it is an unofficial fan work and is not endorsed by, sponsored by, approved by, or affiliated with the relevant rights holders.
