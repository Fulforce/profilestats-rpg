# Changelog

## 1.0.0 - 2026-07-12

Initial stable release.

### Added

- Versioned configuration, storage, theme, XP, and Action contracts.
- Public GitHub activity collection with bounded retries, pagination, safe errors, and completeness warnings.
- Explainable XP source breakdown with monotonic awarded XP.
- Campaign lifecycle with stable journey IDs, locked campaign definitions, completion archives, abandonment, daily logs, and deterministic lifecycle events.
- Standard and compact static SVG renderers with shared view model, accessible descriptions, sanitized bundled SVG assets, and visual regression coverage.
- Reusable JavaScript GitHub Action with optional generated-file commits and the same engine path used by fork mode.
- Bundled schema-version-1 Middle-earth theme with licensing, provenance, fan-work attribution, and shared contract/render tests.
- Contributor theme template, review checklist, issue/PR templates, and documentation for bundled theme submissions.
- CI, visual checks, reproducible Action bundle verification, Dependabot, CodeQL, and dependency review automation.

### Release Notes

- Normal installations can use `Fulforce/profilestats-rpg@v1`.
- Reproducible installations can pin `Fulforce/profilestats-rpg@v1.0.0` or a full commit SHA.
- The previous verified prerelease remains available as `v1.0.0-beta.3` for rollback.
