# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Examples of behavior that contributes to a positive environment:

- being respectful and constructive
- welcoming new contributors
- accepting differing viewpoints and experiences
- focusing criticism on ideas and code, not people

Examples of unacceptable behavior:

- harassment or discriminatory language
- personal attacks
- publishing private information without permission
- sustained disruption of project work

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that are not aligned with this Code of Conduct.
